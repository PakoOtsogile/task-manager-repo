## AI Suggestions (prompt and response)

Prompt used: "I'm doing exploratory testing on a task manager app. The scope is: adding tasks, completing tasks,
removing tasks, and viewing the task list. Suggest 5 exploratory testing ideas using the SFDIPOT heuristic."

Ideas (generated by Claude in this conversation; replace with your own assistant's output if you ran the prompt elsewhere):

| # | SFDIPOT | Idea |
|---|---------|------|
| 1 | Structure | Look for shared or mutable state inside data structures (default arguments, lists reused between tasks) |
| 2 | Function | Feed add-task invalid titles and priorities: empty, whitespace, None, negative, wrong type |
| 3 | Data / Interfaces | Try ids of unexpected types (string, bool, float) and duplicated ids after removing a task |
| 4 | Platform | Break the persistence file: corrupt, empty, unserialisable data, a write that fails half-way |
| 5 | Operations / Time | Run sequences (add, add, add, remove, add, complete) and edge-size lists (empty, one item) |
